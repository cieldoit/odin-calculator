# odin-calculator

A browser-based calculator created as part of The Odin Project Foundations course.

## About

This project is a simple calculator built using HTML, CSS, and JavaScript. It performs basic mathematical operations and supports continued calculations using previous results.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Chained calculations
- Clear button
- Division by zero error handling
- Rounded decimal results
- Decimal number input
- Prevents multiple decimal points
- Backspace button
- Keyboard support
- Handles consecutive operators
- Starts a new calculation after displaying a result
- Pastel pink and blue design

## Keyboard Controls

- `0-9` - Enter numbers
- `+` - Addition
- `-` - Subtraction
- `*` - Multiplication
- `/` - Division
- `.` - Decimal point
- `Enter` or `=` - Calculate
- `Backspace` - Delete the last digit
- `Escape` - Clear the calculator
